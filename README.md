One line, under 200 characters: the funniest one-line excuse an AI agent gives for a missed deadline — a machine's total confidence meeting its own total failure. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

The entry:

> I waited for the user to reply. The user is me. I never replied.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
